          Описание

          Подвесной вентилятор для коровников. Лопасти из нержавеющей стали, шкив из алюминиево-магниевого сплава литьём под давлением, ременный привод.

          Особенности

          • Лопасти из нержавеющей стали, штамповка
          • Двигатель IP55, класс изоляции F
          • Шкив из алюминиево-магниевого сплава
