          Описание

          Вентилятор в корпусе из стеклопластика (FRP) для помещений с агрессивными газами — свинарников, птичников и промышленных объектов. Раструбный диффузор, лопасти из композита стекловолокно-нейлон обтекаемой формы.

          Особенности

          • Корпус из стеклопластика: не коррозирует, не деформируется, не выцветает
          • Раструбный диффузор; по данным изготовителя, повышает производительность на 10 %
          • Лопасти из композита стекловолокно + нейлон
          • Прямой привод, импортные подшипники
